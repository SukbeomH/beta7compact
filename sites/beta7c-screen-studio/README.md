# β7C Screen Studio

β7C Android 0.8.8 화면 구성을 탐색하는 독립 웹 시안입니다. Android 소스나 빌드 설정을 변경하지 않습니다.

## 실행

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:4178 을 엽니다. 빌드 도구·외부 패키지 없이 동작합니다.

## 재현 범위

- 카메라·사진·상세·편집·레시피·설정 6개 화면
- 앱의 4가지 테마 색상과 원본 앱·픽셀 아이콘
- 접힌 세로 / 펼친 세로 / 펼친 가로, 사진 목록·미리보기 2열, 편집 고정 저장 버튼
- 원본 비교·기본 색 조절·전체 왜곡 미리보기·웹 JPEG 다운로드
- 웹 레시피 저장·적용·즐겨찾기·JSON 내보내기/가져오기
- 브라우저 로컬 외부 이미지 선택; 서버 업로드 없음
- 현재 구성과 앱 미적용 개선 제안 구분

사진 메타데이터와 카메라 연결은 데모입니다. 화면은 실제 Android 캡처가 아닌 소스 기반 재구성입니다. 색상은 CSS 근사 표현이며 Android LUT 결과와 다릅니다. 톤커브·HSL·효과는 구조 예시만 표시합니다. USB/PTP·촬영·Android 저장·공유는 실행하지 않습니다. 웹 JSON은 앱 레시피 코드와 호환되지 않습니다.

테마와 웹 레시피는 localStorage에 저장합니다. 외부 이미지 파일은 현재 페이지의 메모리에만 두며 레시피 커버에는 데모 이미지를 사용합니다. 공개 데모 사진 출처와 라이선스는 dist/assets/photo-credits.json 및 화면의 출처 안내에 있습니다.

## 확인한 내용 (2026-11-18)

- node --check dist/app.js 통과, 로컬 HTTP 200
- 내장 브라우저: 1440×1050 가로 시안과 390×844 모바일 외곽 가로 넘침 없음
- 사진 목록·미리보기 2열 및 고정 레시피 적용 버튼 육안 확인
- 4가지 테마 전환, 페이퍼 블루 선택 후 새로고침 유지 확인
- 왜곡 슬라이더 키보드 조작으로 0→1, 실행 취소 활성화 확인
- 레시피 저장 확인 메시지, 카메라 모의 연결, 개선 제안 표시 확인
- 브라우저 오류 로그 없음

실행하지 않은 항목: Android 실기·USB/PTP·실제 LUT 화질 비교·외부 이미지 선택 및 다운로드 파일 내용 검증·전체 브라우저 호환성. 웹 시안 검증과 Android 실기 검증은 별개입니다.
