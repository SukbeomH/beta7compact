# β7C Screen Studio

Android 앱 0.8.8의 화면 구성을 살펴보는 인터랙티브 웹 시안입니다. 카메라, 사진, 사진 상세, 편집, 레시피, 설정 화면을 전환할 수 있습니다. 화면은 앱 소스를 참고해 별도로 재구성했으며 실제 기기 화면 캡처는 아닙니다.

## 시안 열기

[게시된 Screen Studio](https://beta7c-screen-studio.robust-zebra-1280.chatgpt.site/)는 현재 소유자 전용으로 게시되어 있습니다. 다른 계정에서 열리지 않으면 아래 방법으로 저장소의 시안을 실행하세요.

## 로컬에서 열기

저장소 루트에서 다음 명령을 실행합니다. Python 3가 필요하며 별도의 패키지 설치나 빌드 과정은 없습니다.

```sh
cd sites/beta7c-screen-studio
python3 -m http.server 4178 --bind 127.0.0.1 --directory dist
```

브라우저에서 [http://127.0.0.1:4178](http://127.0.0.1:4178)을 엽니다. 종료하려면 서버를 실행한 터미널에서 `Ctrl+C`를 누릅니다. Google Fonts를 사용할 수 없는 환경에서는 대체 글꼴로 표시됩니다.

## 화면 살펴보기

1. 왼쪽의 화면 이름을 눌러 이동합니다. 작은 브라우저 화면에서는 목록이 위쪽에 표시됩니다.
2. **접힌 세로**, **펼친 세로**, **펼친 가로**를 눌러 배치를 비교합니다. 표시된 숫자는 웹 시안의 가상 화면 크기이며 실제 기기의 dp 크기가 아닙니다.
3. 네 가지 테마를 선택합니다. 좁은 화면에서는 **설정 → 앱 테마**에서 선택할 수 있습니다.
4. **사진**에서 데모 사진을 선택한 뒤 **레시피 적용**을 눌러 편집 화면을 엽니다. **왜곡** 탭의 슬라이더와 **원본 비교**를 체험할 수 있습니다.
5. **레시피 저장**으로 브라우저에 웹 레시피를 보관하거나 **사진 저장**으로 웹 미리보기 JPEG를 내려받습니다.
6. **현재 구성**과 **개선 시안**을 전환합니다. 개선 시안의 안내는 Android 앱에 적용된 기능이 아닙니다.

외부 이미지는 **사진 추가**로 선택할 수 있습니다. 파일은 서버에 업로드되지 않고 현재 페이지의 메모리에만 남습니다. 새로고침하면 다시 선택해야 합니다. 한 번에 최대 50개, 파일당 최대 64 MiB를 선택할 수 있으며 이미지 표시 가능 여부는 브라우저에 따라 다릅니다.

## 웹 시안과 Android 앱의 차이

| 항목 | 웹 시안 |
| --- | --- |
| 카메라 연결 및 진단 | 연결 상태와 로그는 데모입니다. USB, PTP 명령과 실제 촬영을 실행하지 않습니다. |
| 사진과 LUT | 사진은 공개 데모 이미지이며 LUT 색은 CSS 근사 표현입니다. Android 출력과 일치하지 않습니다. |
| 세부 조정 | 기본 조정, 원본 비교, 전체 사진 왜곡은 미리 볼 수 있습니다. 톤커브, HSL, 효과는 화면 구성 예시입니다. |
| 사진과 레시피 저장 | JPEG는 브라우저에서 내려받습니다. 웹 레시피는 브라우저 저장소에 보관하며 Android의 `b7c1:` 코드나 QR과 호환되지 않습니다. |
| 여러 장 선택 | 선택한 첫 사진을 웹 편집기에 엽니다. Android의 일괄 처리를 재현하지 않습니다. |
| 사진 커버 | 웹 레시피는 데모 사진을 커버로 사용합니다. 외부 이미지로 만든 레시피에도 데모 커버를 사용합니다. |

웹 테마와 레시피는 해당 브라우저의 로컬 저장소에 남습니다. 브라우저 데이터를 삭제하거나 다른 브라우저를 사용하면 표시되지 않습니다. 데모 이미지 출처는 [photo-credits.json](dist/assets/photo-credits.json)과 사이트 하단의 **데모 사진 출처**에서 확인할 수 있습니다. 사진은 [Unsplash License](https://unsplash.com/license)를 따릅니다.

## 확인 기록

2026-11-18에 로컬 서버의 HTTP 응답과 JavaScript 문법을 확인했습니다. 브라우저에서 가로 화면의 사진 2열 배치와 고정 버튼, 모바일 화면의 가로 넘침, 네 가지 테마 전환, 페이퍼 블루 재실행 유지를 확인했습니다. 왜곡 슬라이더, 레시피 저장, 카메라 모의 연결, 개선 제안 표시도 확인했습니다.

Android 실기, USB·PTP 통신, 앱 LUT와의 화질 비교, 외부 이미지 선택 및 내려받은 JPEG 내용, 전체 브라우저 호환성은 이 웹 시안 검증에서 확인하지 않았습니다. 앱의 검증 결과는 [프로젝트 README](../../README.md#검증-상태)를 참고하세요.
