# α7C 연결 진단과 실기 확인

대상은 Sony α7C 1세대 ILCE-7C다. 이 절차는 카메라 상태를 변경하는 명령 없이 연결 근거를 모으기 위한 것이다. 이번 문서 작성에서는 α7C 실기 검증을 수행하지 않았다.

## 앱에서 진단하기

1. 진행 중인 가져오기가 끝날 때까지 기다린다. 카메라와 폰을 데이터 케이블로 연결한다.
2. 카메라 탭에서 USB 접근 권한을 허용한다.
3. 설정의 카메라 진단을 열고 카메라에서 직접 확인한 모드를 선택한다. 확실하지 않으면 미확인을 선택한다.
4. 진단을 실행하고 결과 화면을 확인한다.
5. 비교 자료가 필요하면 결과를 검토한 뒤 공유 버튼을 누른다. 자동 저장·자동 전송은 하지 않는다.

모드 선택은 사용자가 붙이는 기록이다. 앱이 VID/PID나 인터페이스만 보고 MTP 또는 PC Remote를 판정한 결과가 아니다. 모드를 바꾼 뒤에는 새로 진단해야 한다.

## 결과를 읽는 방법

| 항목 | 의미와 한계 |
| --- | --- |
| VID/PID | USB 제품 식별값. 같은 모델이라도 모드에 따라 달라질 수 있다. 개별 카메라 일련번호가 아니다 |
| 권한 | Android가 앱의 USB 접근을 허용했는지 표시한다. 권한이 있어도 PTP 통신 성공은 보장하지 않는다 |
| 구성·인터페이스·endpoint | Android가 열거한 구조. 목록에 보이는 모든 구성을 활성화하거나 테스트하지 않는다 |
| 활성 구성·alternate | 기존 읽기 요청으로 확인한 현재 상태. 앞 단계가 실패하면 결과에 없을 수 있다. USB 구성을 변경하지 않는다 |
| 단계·시간·실패 분류 | 실패한 위치를 좁히는 자료. 지연 시간 하나만으로 카메라 성능이나 호환성을 판단하지 않는다 |
| 지원 명령·속성 | `GetDeviceInfo`가 광고한 코드 목록. 실제 실행 가능 여부와 현재 설정에서의 쓰기 허용 여부는 별도다 |
| 미지원 인터페이스 | 현재 앱의 still-image bulk 경로로 사용할 수 없다는 뜻이다. 해당 카메라가 모든 원격 제어를 지원하지 않는다는 뜻은 아니다 |

공유 보고서는 정해진 필드만 사용한다. 일련번호·MAC·파일명·파일 해시·원시 패킷을 포함하지 않는다. 기기가 반환한 모델·펌웨어 문자열은 로컬 화면에서만 보여 주고 공유에서는 제외한다. 기존 고정 이벤트 진단 로그와 별도이며 사용자 동작으로만 공유한다. 공유 전 화면을 확인한다.

## MTP 기준선

1. 카메라에서 스마트폰 제어를 끈다. PC Remote 연결 방법이 USB라면 PC Remote도 끈 뒤, 설정 → USB 연결 → MTP를 선택한다. Android 폰의 USB 설정 이름과 혼동하지 않는다.
2. 연결·권한 허용 후 앱에서 모드를 MTP로 기록하고 진단한다.
3. 제품 식별값, 인터페이스, 권한, 응답 결과를 보관한다.
4. 진단이 끝나면 사진 목록을 새로고침하고 사진 한 장을 가져온다.
5. 케이블을 분리했다가 다시 연결하고 진단·가져오기를 반복한다.

완료 기준은 지원 정보 조회뿐 아니라 기존 가져오기 재진입까지 정상인 것이다. 진단 성공만으로 원본 전송 회귀 검증이 끝난 것은 아니다.

## PC Remote 비교

먼저 [ILCE-7C 공식 PC Remote 설명서](https://helpguide.sony.net/ilc/2020/v1/en/contents/TP1000156203.html)를 따른다. 카메라 메뉴에서 스마트폰 제어를 끄고, 네트워크 → PC Remote 기능 → 연결 방법을 USB로 설정한 뒤 PC Remote를 켠다. 진단 앱이 이 설정을 대신 바꾸지는 않는다.

1. MTP 기준선 결과를 확보한 뒤 케이블을 분리하고 카메라에서 모드를 바꾼다.
2. 다시 연결하고 필요하면 Android USB 권한을 새로 허용한다.
3. 앱에 PC Remote라고 기록하고 진단한다.
4. MTP 결과와 제품 식별값·인터페이스·endpoint·실패 단계를 비교한다.
5. 미지원 인터페이스나 PTP 실패가 나오면 결과만 남긴다. 임의 opcode를 보내거나 설정 변경을 시도하지 않는다.
6. PC Remote를 끄고 설정 → USB 연결을 MTP로 되돌린 뒤 사진 가져오기가 정상인지 확인한다.

ILCE-7C의 USB 연결 메뉴는 Auto·Mass Storage·MTP이고, PC Remote는 별도의 네트워크 메뉴에 있다. USB Streaming 중에는 PC Remote를 사용할 수 없으므로 스트리밍도 종료한다. [USB 연결 설명서](https://helpguide.sony.net/ilc/2020/v1/en/contents/TP1000115335.html) · [USB Streaming 설명서](https://helpguide.sony.net/ilc/2020/v1/en/contents/TP1000553122.html)

같은 앱 진단에서 PC Remote가 실패해도 Sony 공식 SDK/Command의 미지원으로 결론 내리지 않는다. 이 앱에는 Sony 전용 세션 초기화나 원격 제어 프로토콜이 구현되어 있지 않다.

## 실패·중단 확인

- 카메라 미연결, 권한 거부, Sony 장치 여러 대 연결을 구분한다.
- 진단 도중 케이블을 분리한 뒤 오류 표시와 다시 실행 가능 여부를 확인한다.
- 가져오기 중 진단을 시도해 USB를 동시에 점유하지 않는지 확인한다.
- 블로킹 USB 호출은 timeout까지 취소가 늦을 수 있다. 앱 종료만으로 카메라 상태 복구를 보장하지 않는다.
- 카메라 재부팅 등 설명되지 않는 변화가 있으면 반복 요청을 중단하고 해당 모드와 실패 단계만 기록한다.

호환성 판정 근거와 공식 자료의 접근 범위는 [Sony 지원 조사](SONY_SUPPORT_RESEARCH.md)에 정리했다.
