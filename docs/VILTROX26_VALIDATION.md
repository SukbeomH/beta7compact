# α7C + Viltrox 26mm F2.8 EVO FE 촬영·비교 체크리스트

2026-11-18. 대상은1세대 α7C(ILCE-7C)와 Sony E용 Viltrox AF 26mm F2.8 EVO FE다. **현재 이 조합의 JPEG가 이미 왜곡 보정됐다고 확인한 상태가 아니다.** 아래 절차로 카메라 내 보정의 효과와 공식 비RAW LCP의 추가 효과를 구분한다. 앱 구현과 실기 촬영은 아직 하지 않았다.

우선순위는 사용자의 지정에 따라 **Viltrox → 나머지 렌즈**다. Sigma와 SG-image는 이번 샘플에 섞지 않는다. 권리 조건은 [공식 LCP 사용·재배포 조사](VILTROX26_PROFILE_RIGHTS.md), 구조 검토는 [도입 가능성 조사](LENS_PROFILE_FEASIBILITY.md)를 참고한다.

## 먼저 알 수 있는 것과 아직 모르는 것

Sony는 대응 렌즈에서 JPEG 렌즈 보정을 제공하며 렌즈에 따라 왜곡 보정을Auto로 고정할 수 있다고 설명한다.[1] Viltrox 제품 설명도 카메라 내 보정을 언급한다.[4] 이것만으로 사용자의 α7C와 렌즈에서 실제 적용되는지는 확정할 수 없다. 메뉴가Auto라는 사실도 픽셀에 적용됐다는 증거와 구분한다.

확인하려는 항목은 다음과 같다.

- 카메라의 왜곡 보정Off/Auto 전환이 실제로 가능한가?
- 같은 구도의 원본JPEG에서 직선의 휨과 가장자리 화각이 달라지는가?
- 공식 비RAW LCP를 적용하면 남은 왜곡이 줄어드는가, 반대 방향으로 휘는가?
- 처리 이력을 메타데이터로 일관되게 판별할 수 있는가?

## 1. 촬영 전 상태 기록

- [ ] 바디 모델ILCE-7C와 바디 펌웨어 버전 기록.
- [ ] 렌즈의 정확한 FE 모델과 현재 펌웨어 버전 기록. 확인이 안 되면unknown으로 기록.
- [ ] 기존 카메라 설정을 메모해 촬영 후 복구할 수 있게 준비.
- [ ] 메뉴의 **렌즈 보정 → 왜곡 보정**에서끔/자동 선택 가능 여부 확인. 자동 고정·항목 비활성·항목 없음 중 무엇인지도 기록.
- [ ] 음영 보정과 색수차 보정의 현재 값도 기록. 이번 비교에서는 두 값을 일정하게 유지.

이 절차를 위해 바디/렌즈 펌웨어를 먼저 업데이트하지 않는다. 펌웨어가 바뀌면 비교 조건이 달라진다. 렌즈 보정을 강제로 끄기 위한 우회도 하지 않는다.

## 2. 카메라 설정

정확한 페이지 번호 대신 항목명으로 찾는다. 아래는 **검증용 권장 설정**이며 이번에 카메라에 적용한 값이 아니다.

| 항목 | 권장 값/동작 | 이유 |
| --- | --- | --- |
| 촬영 | 정지 이미지·M 모드·단발 | 촬영 간 노출 변화와 연사 선택 혼동 줄이기 |
| 파일 형식 | RAW & JPEG | 같은 노출의ARW/JPEG 쌍 보존[2] |
| JPEG | L:24M·3:2·가능한 최고 품질 | 풀프레임L의 표준JPEG는6000×4000[3] |
| APS-C/Super 35mm | 끔 | 풀프레임 화각 고정. 이 렌즈는FE 모델 기준[5] |
| 줌 | 광학 줌만·확대/디지털 줌 사용 안 함 | 크롭/배율 조건 고정 |
| ISO·화이트밸런스 | ISO100부터, WB 고정 | 노출/색 변화 줄이기. 부족하면ISO를 고정값으로 올려 기록 |
| 조리개 | 우선F2.8과F8 두 묶음 | 개방/조인 상태 비교. 묶음 사이 셔터속도를 조절해 적정 노출 유지 |
| 초점 | 조리개 묶음마다 초점 확인 후MF 고정 | Off/Auto 비교 중 초점 이동 방지 |
| 삼각대 | 사용, 손떨림 보정끔 권장, 2초 타이머 | 위치/진동 변화 줄이기 |
| 톤/효과 | PP끔, HDR/사진 효과 사용 안 함, DRO끔 권장 | 렌즈 왜곡 이외 처리 변수 줄이기 |
| 렌즈 음영/색수차 보정 | 평소 값 유지·전 샘플 동일 | 이번에는왜곡 보정만 비교 |
| 왜곡 보정 | 아래 순서에서만 전환 | 변경 변수 하나로 제한 |

조리개를 바꾸면 필요한 셔터속도도 달라진다. 흔들림·포화·암부 노이즈가 심하면 재촬영한다. 파일 해상도만으로 보정 여부를 판정하지 않는다. 보정 후에도6000×4000으로 재샘플링될 수 있다.

## 3. 촬영 대상과 위치

- [ ] 움직이지 않는 평평한 격자/타일벽/창틀을 고른다. 인쇄 종이가 휘거나 실제 건축선이 굽은 경우는 피한다.
- [ ] 가로·세로 직선이 화면 중앙과 네 가장자리 근처에 모두 들어오게 한다. 비교할 선은 잘리지 않게 약간의 여백을 둔다.
- [ ] 카메라를 벽과 가능한 평행하게 두고 수평을 맞춘다. 처음에는 약2~3m 거리에서 시작하고 실제 거리를 기록한다. 이는 권장 시작점이며 정해진 캘리브레이션 거리는 아니다.
- [ ] 삼각대·카메라·피사체를 고정한다. 렌즈/카메라 위치를 보정 설정 사이에 바꾸지 않는다.
- [ ] 일정한 조명에서 촬영한다. 얼굴 사진은 첫 검증에 필요하지 않다.

카메라 기울기로 생기는 선의 수렴과 렌즈 때문에 생기는 선의 휨을 구분한다. 자동 Upright로 수렴을 먼저 없애면 원인 판정이 어려워진다.

## 4. 샘플 촬영 순서

### A. 왜곡 보정끔/자동을 선택할 수 있을 때

**같은 위치에서6번 촬영 → ARW6개+JPEG6개**가 기본 세트다.

| 순서/메모ID | 조리개 | 왜곡 보정 | 기록할 것 |
| --- | --- | --- | --- |
| A01 | F2.8 | 끔 | 실제 원본 파일명, 셔터/ISO, 메뉴 값 |
| A02 | F2.8 | 자동 | 초점/구도/노출은A01과 동일 |
| A03 | F2.8 | 끔으로 복귀 | A01 재현 여부·삼각대 이동 여부 |
| A04 | F8 | 끔 | 이 묶음의 초점/적정 노출 재설정 |
| A05 | F8 | 자동 | 초점/구도/노출은A04와 동일 |
| A06 | F8 | 끔으로 복귀 | A04 재현 여부 |

각 사진을 찍기 전 메뉴의 실제 값과 파일 번호를 메모한다. 메뉴 상태 사진도 가능하면 남긴다. “설정 변경 버튼을 눌렀다”와 “변경이 반영됐다”를 구분한다. 파일을 임의로 덮어쓰지 말고A01 같은ID는 메모에서 원본 파일명과 연결한다.

먼저A01/A02/A03 세 쌍만으로도 예비 판정은 가능하다. F8 세트는 재현성을 확인하고 조리개에 따른 품질을 보는 권장 추가 세트다. 필요하면 가까운 직선 대상에서도 동일 순서를 반복하되 별도 거리 세트로 분리한다.

### B. 자동 고정이거나 메뉴가 비활성/없을 때

1. 정확히 어느 상태인지와 가능한 메뉴 값을 기록한다. 비활성/없음을 자동 적용 완료 또는 미보정이라고 해석하지 않는다.
2. 같은 조건에서F2.8 세 쌍과F8 세 쌍을 촬영한다. ID는B01~B06, 왜곡 보정 값은실제 상태 그대로 기록한다.
3. 이 세트로는 카메라의 Off/Auto 효과를 직접 비교할 수 없다고 표시한다. 미현상RAW와JPEG의 기하 차이를 확인할 수 있는지PC에서 별도 검토한다.
4. RAW 뷰어에서 내장 프로파일이 강제로 적용되어 끌 수 없으면 그 렌더를 “미보정 RAW 기준”으로 쓰지 않는다. 현재로서는 카메라 보정 여부를 **미확정**으로 유지한다.

## 5. 원본 보존과 공유 묶음

- [ ] 촬영 후 카드의 원본 ARW/JPEG 쌍을 확보한다. 앱의 **사진 저장/레시피 적용**으로 만든 결과나 메신저 재압축본을 원본으로 쓰지 않는다.
- [ ] 가능하면 카드에서 PC로 복사한JPEG와 앱에서 가져온 원본 JPEG의 SHA-256을 대조한다. 서로 같으면 바이트가 보존된 전송 경로로 확인할 수 있다. 해시 일치가 광학 보정 여부를 의미하지는 않는다.
- [ ] 바디·렌즈 버전, 설정, 거리, 순서ID↔원본 파일명, 조리개/셔터/ISO를 `capture-notes.txt`로 남긴다.
- [ ] 원본과 메모를ZIP으로 묶는다. 화면 캡처만으로 픽셀/EXIF를 검증하지 않는다.
- [ ] 전체 메타데이터에는 GPS·시리얼 등 개인 정보가 있을 수 있다. 임의로 원본을 외부 업로드하지 않는다. 공유한다면 사용자가 공개할 범위를 선택한다.
- [ ] 촬영이 끝나면 기록해 둔 평소 설정으로 되돌린다.

자료 예시: 원본12개(또는 예비6개), 설정 메모, 메뉴 상태 사진. 프로파일ZIP을 같은 공유 묶음이나 GitHub에 재배포하지 않고 공식 다운로드 주소와 해시만 남긴다. USB/AF 진단 로그만으로는 렌즈의 광학 보정 여부를 알 수 없다.

선택한 태그만 읽는PC 명령 예시다. 이번에는 ExifTool이 설치돼 있지 않아 실행하지 않았다. `samples`에는 검증 대상 복사본만 둔다.

```sh
exiftool -G1 -a -s -FileName -FileType -ImageWidth -ImageHeight \
  -Make -Model -LensModel -LensID -FocalLength -FNumber -Software \
  -DistortionCorrectionSetting -DistortionCorrection \
  -DistortionCorrParamsPresent samples/*.JPG > metadata.txt
shasum -a 256 samples/*.JPG samples/*.ARW > hashes.txt
```

태그가 없거나 ExifTool이 해석하지 못하면unknown으로 기록한다. `DistortionCorrectionSetting=Auto`와 `DistortionCorrection=Applied`는 의미가 다르고, 후자도 실제 α7C 샘플에서 신뢰성이 확인돼야 한다. 날짜·설정 메모와 충돌하면 자동 판정하지 않는다.

## 6. PC 비교 순서

실행할 때는 사용한 프로그램/버전과 실제 선택된 프로파일명을 남긴다. 아래 절차는 아직 실행하지 않았다.

1. 원본 JPEG를 별도 검증 카탈로그/복사본으로 연다. 가져오기 프리셋·자동 렌즈 보정·AI·Upright/Transform·수동 왜곡·크롭을 해제하고 변경 전 상태를 기록한다. JPEG 픽셀에 이미 반영된 카메라 보정은 체크박스를 꺼도 되돌아가지 않는다.
2. [공식 ZIP](https://cdn.shopify.com/s/files/1/0104/0380/7298/files/26f2.8FE_Lens_Correction_Profiles.zip?v=1792983630) 중 **`Viltrox 26mm F2.8 FE.lcp`**를 사용한다. RAW 표시 파일과 Nikon Z 파일을 대신 선택하지 않는다. 사용자 LensProfiles 경로 설치는 공식 ZIP의 안내를 참고한다.
3. 같은 JPEG에서 **D0: 프로파일 꺼짐**과 **D100: 비RAW 프로파일 왜곡100·비네팅0**의 가상 사본을 만든다. 자동 색수차 제거/수동 왜곡은 끔, Transform은 기본값으로 두고 색/톤/선명도 설정도 같게 한다. 기하 효과를 분리하기 위한 검증 설정이다.[6]
4. 처음에는 Constrain Crop/자동 크롭을 끄고 가장자리 이동·빈 영역을 확인한다. 다음에 최종 크롭을 적용해 실제 잃는 화각을 따로 기록한다. 내보낸 픽셀 크기가 같아도 화각은 줄어들 수 있다.
5. A01-D0/A02-D0/A03-D0를 먼저 비교한다. 그다음 각 JPEG의 D0/D100을 비교한다. 확대율과 중심을 맞추되 자유변형으로 직선 휨을 숨기지 않는다. 중앙/상하좌우 선과 모서리를100%에서도 확인한다.
6. JPEG에서 프로파일이 표시되지 않거나 다른 프로파일로 대체되면 중단해 상태를 기록한다. RAW용으로 강제 대체하거나 일반35mm 계수를 쓰지 않는다.
7. 필요하면 원본 ARW를 지원 RAW 현상기에서 별도로 열고 기하 보정·내장 보정의 꺼짐 여부를 확인한다. 실제 센서 RAW 현상과 내장 JPEG 미리보기를 구분한다. 본 앱의 ARW 편집은 내장 JPEG이므로 미보정 RAW 비교 도구가 아니다.

D0/D100은 동일 원본에서 각각 생성하고, D100의 저장 결과를 다시 D100 처리하지 않는다. JPEG 재인코딩 차이와 리사이즈 차이를 광학 보정의 증거로 삼지 않는다. 공식 PDF의 예시 화면은 다른 Viltrox35mm 렌즈를 사용한 일반 안내이며26mm+α7C의 실증이 아니다.

## 7. 결과 해석

| 관찰 | 가능한 해석 | 앱 도입 판단 |
| --- | --- | --- |
| Off에서 휜 선이 Auto에서 곧아지고 Off 복귀에서 다시 휨 | 해당 샘플에서 카메라 왜곡 보정 효과의 증거 | Auto JPEG에 전체 프로파일을 기본 재적용하지 않음 |
| Auto D0가 곧은데 D100에서 반대 방향으로 휨 | 중복 보정 또는 입력과 맞지 않는 프로파일 의심 | 추가 보정 도입 중단. 둘 중 어느 원인인지 단정하지 않음 |
| Off/Auto 모두 같음 | 왜곡이 작음·미대응 렌즈·변경 미반영·비교 조건 문제 등 | 미보정 또는 완전 보정으로 확정하지 않음 |
| 특정 JPEG에서 D100이 배경 선을 개선 | 해당 JPEG/설정에 대한 후보 근거 | 다른 조리개/거리·크롭·모서리·반복 샘플까지 검증 |
| 같은 설정의 반복 샘플부터 서로 다름 | 위치·초점·노출·대상 변화 가능성 | LCP 평가 전에 촬영 조건을 다시 맞춤 |
| Auto 고정이고 미보정 RAW 기준도 없음 | 카메라 적용 여부를 분리할 자료 부족 | 기본 꺼짐/unknown 유지 |
| D100이 직선을 곧게 하지만 얼굴을 더 늘림 | 광학 직선 보정과 인물 자연스러움의 목표 차이 | 인물 개선 성공이라고 보고하지 않음 |

이번에는 정량 오차나 합격 임계값을 측정하지 않았다. 통과 기준은 설정별 재현성, 선의 개선, 과보정 없음, 수용 가능한 화각/모서리 손실이며 실제 자료를 본 뒤 판단한다. 촬영한 JPEG 모두에 한꺼번에 보정을 적용하지 않는다.

## 8. 수동 왜곡 효과라는 별도 선택지

사용자는 이미 보정된 사진에 보정 계수를 바꿔 과도하거나 약한 왜곡 효과를 주는 방향도 제안했다. 이 경우 제조사 프로파일 기반 보정과 별도로 **수동 왜곡 조절**을 검토할 수 있다.

- 원본 JPEG를 기준으로 기본값0, 배럴↔핀쿠션 방향의 사진 전체 변형을 제공하는 개념이다. 특정 렌즈의 물리적 복원이라고 표시하지 않는다.
- 이미 카메라 보정이 반영된 JPEG에 추가 효과를 줄 수 있지만, 정확한 카메라 보정량을 복원/감소시키는 기능과는 다르다. 크롭된 정보는 복구할 수 없다.
- LCP 보정량50%는 “촬영 때 왜곡이 절반 남은 상태”라는 보증이 아니며, 이미 보정된 JPEG에 적용하면 추가 보정일 수 있다. 계수별 수치를 임의로 늘리는 방식도 변환의 안정성이나 자연스러움을 보장하지 않는다.
- 원본 비교·초기화·명시적 적용·크롭 미리보기와 주변부 화질 검증이 필요하다. 얼굴과 배경이 함께 변하므로 이전 국소 보정의 실패를 피한다고 보장하지 않는다.
- 독립적인 효과 엔진으로 만들면 Viltrox LCP에 의존할 필요가 없다. 공식 계수를 사용/변환하면 해당 데이터의 권리 검토는 그대로 남는다.

현재 우선순위는 원본과 공식 프로파일을 비교해 추가 조절의 실제 필요를 판단하는 것이다. 정확한 보정에는 이득이 없고 창작 효과만 선호된다면 별도 기능으로 제안할 수 있지만, 이번에는 구현하지 않는다.

## 현재 진행 상태

준비 완료: 공식 카메라 메뉴/자료 재조회, 공식 LCP 구조·해시 재확인, 동봉 PDF3페이지 시각 확인, 촬영/비교/공유 체크리스트 작성.

대기: 사용자 촬영 원본·메뉴 상태·버전/설정 메모. 아직 JPEG 보정 적용 여부, LCP 개선 효과, α7C 메타데이터 신뢰성은 미확정이다. 앱 구현·카메라 조작·프로파일 설치·사진 보정·빌드·테스트·배포는 실행하지 않았다.
