# TASK M5a: 편집기(톤커브·HSL) + 레시피 공유

먼저 읽기: docs/ARCHITECTURE.md, docs/M2-ENGINE.md, docs/RESULT_M2.md, docs/LUT-FORMAT.md. M2 엔진 위에 확장. BLE·USB·가져오기 코드는 건드리지 말 것.

## 범위
1. 편집 파라미터 추가(레시피 JSON version 올림, 이전 버전 레시피 읽기 호환):
   - 톤커브: RGB 공통 + R/G/B 개별, 제어점 2~16개(단조 3차 보간, 예: Fritsch–Carlson), 화면에서 점 추가·이동·삭제.
   - HSL: 8색(빨강·주황·노랑·초록·청록·파랑·보라·자홍) 각 색조/채도/휘도 ±100, 색상 경계 부드럽게 가중.
   - 하이라이트/섀도, 대비, 채도·바이브런스, 스플릿 톤(하이라이트·섀도 색조/채도, 균형).
   - 파이프라인 순서를 docs/M2-ENGINE.md에 갱신(입력 변환 → WB/노출 → 톤·HSL → LUT(강도) → 그레인·비네트 등, 근거 기록). GPU와 CPU 참조 구현 모두 반영, 일치 테스트 갱신.
2. 레시피 → LUT 굽기: 현재 색 파라미터(그레인·비네트 등 공간 효과 제외)를 33³ `.cube`로 내보내기(SAF 저장). 내보낸 LUT를 다시 가져와 적용 시 CPU 참조와 ΔE 검사.
3. 레시피 공유:
   - 텍스트 코드: `b7c1:` + base64url(압축 JSON) + 체크섬. 붙여넣기/공유 인텐트로 가져오기, 잘못된 코드는 한 줄 사유로 거부, 크기 상한.
   - QR 표시·스캔: 표시는 외부 라이브러리 없이 구현 가능하면 직접(작은 QR 인코더, 라이선스 주의, 타 코드 복사 금지), 스캔은 ML Kit 등 외부 의존 금지 → M5a에서는 QR "표시"만, 스캔은 카메라 앱으로 읽은 텍스트 붙여넣기로 대체하고 RESULT에 기록. 
   - 사용자 `.cube`를 쓰는 레시피 공유 시: LUT 데이터는 코드에 넣지 않고 "LUT 필요(이름)" 표시, 수신 측에 없으면 적용 전 안내. 내장 LUT는 id로 참조.
   - 레시피 가져오기 시 이름 충돌 처리, 필드 범위 검증(악성 입력에 크래시·메모리 폭주 없음).
4. UI: 편집 화면 탭(기본/톤커브/HSL/효과), 슬라이더 더블탭 초기화, 실행 취소/다시 실행, 레시피 저장·이름 변경·복제·삭제, 공유 버튼. 폴더블 펼침 시 미리보기+패널 2분할.
