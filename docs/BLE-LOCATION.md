# M1 BLE 위치 전송 근거

2026-11-15 확인. 공개 프로토콜 설명만 이용해 패킷 인코더와 Android GATT 연결을 구현했습니다. 소니 SDK·타 앱 코드·자산·실기 로그를 포함하지 않습니다. A7C fw 2.03에서의 실제 전송은 아직 미확인입니다.

## 공개 자료

- [ILCE7M3ExternalGps 프로토콜](https://github.com/whc2001/ILCE7M3ExternalGps/blob/219a05745bdcbbe8ede1442b9ba356d6fd8e1e29/PROTOCOL_EN.md): 광고·위치 서비스·DD21 설정 비트·패킷 표·완전한 예시 벡터의 일차 근거입니다. [프로젝트 설명](https://github.com/whc2001/ILCE7M3ExternalGps/blob/219a05745bdcbbe8ede1442b9ba356d6fd8e1e29/README_EN.md)은 ILCE-7M3용 공개 분석이며 개발 종료 상태라고 명시합니다. 다른 바디에서의 실증과 구분합니다.
- [sony_camera_bluetooth_external_gps](https://github.com/anoulis/sony_camera_bluetooth_external_gps/tree/931f87caa00853718c212bb2591b2f115e010936): 본딩, 큰 MTU 및 위치 쓰기를 이용하는 커뮤니티 사례입니다. 앱 코드는 가져오지 않았습니다. 시각·시간대 처리는 이 스크립트를 복제하지 않고 위 프로토콜 표를 따릅니다.
- [Android BLE 데이터 전송](https://developer.android.com/develop/connectivity/bluetooth/ble/transfer-ble-data): 서비스 검색·비동기 GATT 콜백·CCCD 구독의 플랫폼 근거입니다.

## 범위와 형식

Sony Company ID `0x012D`와 제조사 데이터의 카메라 유형을 함께 필터링합니다. 사용자가 고른 카메라에만 OS 본딩을 요청하고, 앱 비공개 설정에 선택 대상을 저장합니다. 주소·광고 원문·좌표는 로그로 출력하지 않습니다.

서비스는 `8000DD00-DD00-FFFF-FFFF-FFFFFFFFFFFF`, 특성은 Bluetooth 기본 UUID의 `DD01`(상태 알림), `DD11`(위치 write with response), `DD21`(설정 읽기)입니다. 설정의 4번 바이트에 `0x02` 비트가 있으면 시간대 필드를 포함합니다. 문서의 “bit 2” 표기는 실제 마스크와 혼동될 수 있어 `0x02`로 테스트합니다.

| 바이트 범위 | 내용 |
| --- | --- |
| 0–1 | 자신을 제외한 길이, big endian |
| 2–10 | 고정 필드와 시간대 유무 플래그 |
| 11–18 | 위도·경도 × 10^7, 부호 있는 32비트, big endian |
| 19–25 | UTC 연·월·일·시·분·초 |
| 26–90 | 0으로 채움 |
| 91–94 | 선택 필드: UTC 표준 오프셋 분·DST 분, 부호 있는 16비트 |

시간대 포함 시 총 95바이트(길이 필드 93), 미포함 시 총 91바이트(길이 필드 89)입니다. 공개 문서 예시의 **전체 바이트 일치**와 음수 좌표·음수 시간대·DST 분리·잘못된 좌표·짧은 설정·알 수 없는 상태를 JVM 테스트합니다. 테스트 벡터는 공개 자료 또는 합성 값이며 실기 위치가 아닙니다.

## 전송 조건과 실패 처리

1. 사용자가 화면에서 켭니다. 정확한 위치·Bluetooth·알림 권한을 확인하고 위치 타입 포그라운드 서비스를 시작합니다.
2. 본딩된 선택 대상에 연결하고 MTU 158을 요청합니다. 협상 결과가 98 미만이면 분할 패킷을 추측해 보내지 않습니다.
3. 서비스 검색 → DD21 읽기 → DD01 CCCD 구독을 직렬 처리합니다. 각 응답은 15초 안에 확인합니다.
4. DD01의 알려진 활성 알림을 받아야 DD11을 씁니다. 알림이 오지 않으면 카메라의 위치정보 연동을 껐다 켜고 재시도합니다. 구독 성공만으로 활성 상태를 추측하지 않습니다.
5. 플랫폼 LocationManager GPS에서 수신한 최근 60초 이내·정확도 100m 이하의 실제 위치만 사용합니다. 시각은 전송 시점의 UTC, 시간대는 폰의 시스템 시간대입니다. 좌표로 시간대를 추정하는 외부 서비스는 사용하지 않습니다.
6. 5–60초 간격으로 쓰고 성공 콜백 후에만 마지막 전송 시각을 갱신합니다. 실패·권한 해제·연동 해제·연결 끊김은 종료하고 원인 한 줄을 표시합니다. 백그라운드에서 자동 재시작하지 않습니다.

DD30·DD31을 요구하는 새 프로토콜은 추가 쓰기를 하지 않고 지원하지 않는다고 표시합니다. DD01 구독을 위한 CCCD 외에는 DD11만 씁니다. EE 페어링 명령·리모컨 FF·Wi-Fi 서비스 쓰기는 없습니다. 본딩은 사용자 선택에 따른 Android OS 절차입니다.

## 남은 실기 확인

카메라 Bluetooth 켬 → 페어링 메뉴에서 폰 확인 → 위치정보 연동 켬 순서를 확인합니다. DD01 최초 활성 알림, MTU, DD21 응답, 카메라 GPS 표시 및 새 사진의 시각·시간대는 [실기 체크리스트](M1-DEVICE-CHECK.md)에서 확인해야 합니다. 문서화된 패킷을 구현했다는 결과가 실기 호환을 보장하지 않습니다.
