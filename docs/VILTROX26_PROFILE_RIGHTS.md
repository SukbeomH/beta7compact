# Viltrox 26mm FE LCP의 앱 사용·재배포 조건 추가 조사

2026-11-18. 결론은 **공식 비RAW LCP가 존재하고 Adobe 프로그램에서 사용하도록 안내하지만, 자체 Android 앱에서의 해석·복사·계수 변환·재배포를 포괄하는 공개 허가는 확인하지 못했다**는 것이다. 금지라고 확정한 것도, 허가를 확보한 것도 아니다. 권리 조건이 미확인인 파일을 APK/GitHub 릴리즈에 동봉하지 않는다.

이번에는 공식 자료 조회와 파일 구조 확인만 했다. 제조사에 연락하거나 앱을 구현하지 않았다. 촬영과 실제 프로파일 효과 검증은 [촬영 체크리스트](VILTROX26_VALIDATION.md)를 따른다.

## 추가로 확인한 근거

1. [공식 FE 다운로드 페이지](https://viltrox.com/pages/af-56-1-7-xf)에 AF 26/2.8 EVO FE Lens Correction Profiles의 ZIP 링크가 있다. Nikon Z용과 구분된다.
2. 해당 ZIP에는 RAW LCP, 비RAW LCP, 중국어 사용 안내 PDF가 있다. 별도 LICENSE/README 파일은 없다. LCP XML에서 저작권·권리·라이선스 요소나 재배포 허용 문구를 찾지 못했다.
3. 동봉 PDF 3페이지를 이미지로 렌더링해 직접 확인했다. Adobe LensProfiles 폴더 설치, Lightroom/Photoshop의 프로파일 선택, 보정 전후 예시다. 앱 개발·변환·재배포 허가 조항은 보이지 않았다. 예시 화면은 Viltrox 35mm F1.8 II를 사용한 일반 안내라서26mm와 α7C의 품질/호환성을 입증하지 않는다.
4. [사이트 일반 약관](https://viltrox.com/pages/terms-of-service) SECTION2는 서비스의 복제·재판매 등에 명시적 서면 허가를 언급한다. 웹 서비스 약관이 특정 LCP에 적용되는 정확한 범위는 미확정이며, 이 문구를 특정 파일의 재배포 허가로 해석할 수 없다.
5. [Intellectual Property Rights 페이지](https://viltrox.com/pages/intellectual-property-rights)에서는 LCP 전용 라이선스 본문을 확인하지 못했다. 외부 링크는 제3자 legal 페이지로 연결되며 조회가 실패했고, viltroxstore.com 링크는 원래 페이지로 돌아왔다. 제목만으로 파일 이용 허가를 추정하지 않는다.
6. 추가 검색에서도 이26mm FE LCP를 Apache/MIT/CC 등으로 제공한다는 공식 조건을 찾지 못했다. 검색에서 미발견이라는 사실이 별도 계약이나 개별 허가가 존재하지 않는다는 뜻은 아니다.

공식 Adobe 설치 안내는 그 용도로 배포한 근거다. 이를 다른 프로그램의 내장 데이터로 자유롭게 사용할 수 있다는 허가로 확대하지 않는다. LCP를 읽는 엔진의 라이선스와 LCP 데이터의 권리는 별개다.

## 확인한 파일 식별 정보

| 대상 | SHA-256 |
| --- | --- |
| 공식 ZIP | `e2def191a0c83b11e8f8f4fe098e5603d6bfa455b8541b71161fe61f992d6c4e` |
| `Viltrox 26mm F2.8 FE.lcp` | `2d9e218b22b43dd6a4d732cd341e70d1e940b25df97a4a8ac6d0381aa6876304` |
| `Viltrox 26mm F2.8 FE - RAW.lcp` | `f440b2cdfb6f894f4ac0629d1b1ff03bd7194ca8f426f55d99290a7496533ccc` |

비RAW 파일은 CameraRawProfile=False, CameraPrettyName=ILCE-7RM5, 센서 배율1.0이며 실제 방사 왜곡 모델을 포함한다. False가 “카메라에서 보정한 JPEG에 덧붙이는 잔여 보정 전용”이라는 뜻은 아니다. 계수도 항등 변환이 아니므로 자동 재적용을 권하지 않는다.

계수를 읽을 수 있다는 사실, 데이터 변환이 가능하다는 사실, 재배포 권한이 있다는 사실을 구분한다. 숫자 데이터의 권리 범위를 일반론만으로 확정하지 않고 실제 파일과 허용 조건을 확인한다.

## 앱에 활용하는 방식별 판단

| 방식 | 현재 확인 범위 | 필요한 확인 |
| --- | --- | --- |
| PC의 Lightroom/Photoshop에 설치 | 제조사가 동봉 PDF로 안내 | 프로그램 이용 조건과 입력 적합성 준수. α7C JPEG 효과는 별도 검증 |
| 사용자가 받은 LCP를 앱에서 로컬로 선택 | APK에서 파일을 직접 배포하지 않는 구조 | Android 등 다른 프로그램에서의 해석·사용 허용 여부, 파일 모델의 지원 범위 |
| APK assets 또는 GitHub 릴리즈에 원본 동봉 | 공개 허가 미확인 | 원본 복사·재배포와 무료/유료 앱 배포 허용 |
| 앱이 제조사 URL에서 자동 다운로드·캐시 | 사용자가 직접 파일을 선택하는 것과 다른 배포 흐름 | 직접 링크 사용·자동 취득·캐시·갱신·재호스팅 조건. 우회 허가로 취급하지 않음 |
| LCP를 JSON/XML/Lensfun 계수로 변환해 동봉 | 파일 형식을 바꿔도 원본 권리 문제가 자동으로 사라지지 않음 | 추출·변환·수정·파생 데이터 배포 허용과 고지 조건 |
| 자체 촬영으로 별도 계수 측정 | 이 LCP의 재배포 의존을 줄이는 경로 | 원본 계수 복사와 독립 측정을 구별하고, 측정 데이터의 출처·권리·적합성 명시 |
| 프로파일 없이 수동 왜곡 효과 제공 | 이 LCP를 사용할 필요가 없는 별도 제품 선택 | 엔진 코드·의존성 라이선스와 품질 검증. 렌즈 보정이나 얼굴 복원으로 표시하지 않음 |

무료 앱도 재배포 조건 확인 대상이다. Lensfun 변환기가 존재하거나 다른 오픈소스 프로그램이 LCP를 읽는다는 사실을 Viltrox 데이터 이용 허가로 대체하지 않는다. 독립 엔진을 만들면 엔진의 선택 폭은 넓어지지만 가져온 데이터의 조건까지 바뀌는 것은 아니다.

## 제조사에 확인할 항목

[공식 문의 경로](https://viltrox.com/pages/contact-us)를 통해 확인할 질문이다. **아직 발송하지 않았다.** 앱의 공개 여부, 무료/유료 배포 범위, 저장소·GitHub APK 배포 방식을 함께 설명하고 파일명·해시를 명시한다.

- 이 비RAW 프로파일은 어떤 바디/펌웨어·왜곡 보정 메뉴 값·크롭·촬영 거리에서 만든 JPEG를 대상으로 하는가? α7C JPEG에도 권장하는가?
- 제조사 LCP를 Adobe 이외의 Android 앱에서 읽어 사용해도 되는가?
- 원본 LCP를 APK와 공개 저장소/릴리즈에 복사해 배포해도 되는가?
- 계수를 추출·정규화·변환하거나 보정량을 조절한 파생 데이터를 배포해도 되는가?
- 앱에서 공식 파일을 직접 내려받아 캐시/갱신하는 방식도 허용하는가?
- 무료/유료 앱, 전 세계 배포, 오프라인 사용에 제한이 있는가?
- 필요한 저작권·출처·변경 고지, 라이선스 원문, 업데이트/사용 중지 조건은 무엇인가? 권리 보유자가 별도라면 누구에게 허가받아야 하는가?

기술 답변만 받으면 재배포 권한이 해결됐다고 보지 않고, 사용/배포 허가만 받으면 α7C JPEG 품질이 검증됐다고 보지도 않는다. 두 조건이 모두 충족돼야 내장 프로파일 채택을 판단한다.

## 남은 상태

실행: 공식 페이지·약관·IP 페이지 추가 조회, ZIP 목록/해시·LCP 모델 확인, 동봉 PDF의3페이지 시각 확인. 공개된 앱 재배포 허용 조건은 확보하지 못했다.

미실행: 제조사 문의/허가, 사용자 원본 분석, PC에서 실제 보정, Android 엔진/프로파일 파서 구현, 파일 변환, 테스트·빌드·배포. 파일과 PDF는 임시 경로에서만 확인했고 프로젝트 assets나 GitHub에 추가하지 않았다.
