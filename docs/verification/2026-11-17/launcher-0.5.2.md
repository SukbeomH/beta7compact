# 0.5.2 실제 런처 검증

2026-11-17, 연결된 SM_F971N Android 폰에서 진행했다. 기기 식별자와 개인 홈 화면 스크린샷은 공개 저장소에 포함하지 않는다.

- 게시 APK 인증서 검사 통과.
- `adb install -r dist/beta7compact-0.5.2-debug.apk`: Success. 앱 삭제·데이터 초기화 없음.
- 설치된 versionName 0.5.2 / versionCode 9 확인.
- 실제 런처 앱 서랍과 Finder 추천 앱에서 새 아이콘 확인.
- 흰색 외곽 프레임 없음. 카메라·렌즈·코드 칩과 β7C 문자가 모두 보이며, 마스크에 잘린 부분은 관찰되지 않음.
- 앱 서랍 화면에서 아이콘 배경은 약170px 폭, 카메라·칩은 약140px 폭으로 배경의 약80%를 차지한다(1248px 폭 스크린샷 시각 추정). 크기는 주변 앱 아이콘과 균형을 이룬다.
- β7C는 식별되지만 작은 문자이므로 가독성 한계는 있음. 흰색 런처 배경 자체는 남아 있으며 제거한 것은 전경의 외곽 프레임이다.

확인 범위는 현재 표시된 화면·런처 설정이다. 폴더블 다른 화면, 다른 테마·아이콘 크기·OEM 마스크 전부를 확인한 것은 아니다. 앱 데이터 내용과 카메라 기능은 이번 검증 범위 밖이다.
