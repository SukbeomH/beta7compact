# 공개 웹 미리보기 검증

2026-11-19에 [β7C Screen Studio](https://beta7c-screen-studio.robust-zebra-1280.chatgpt.site/)의 공개 접속과 주요 데모 기능을 확인했다. 이 기록은 Android 앱이나 카메라 연결의 검증 결과가 아니다.

## 환경과 접속

- 사이트 설정은 전체 공개였고, 로그인 정보를 사용하지 않은 HTTP 요청은 200을 반환했다.
- Mac의 Aside 브라우저와 Samsung SM-F971N의 삼성 인터넷에서 공개 URL을 열었다. Mac 브라우저에서 390 × 844 뷰포트도 확인했다. 이 설정은 실기 iPhone 검증이 아니다.
- Android 화면을 재구성한 웹 데모이며 실제 카메라 연결이나 촬영을 하지 않는다는 안내가 표시됐다.

## 실행한 검증

| 항목 | 확인한 결과 |
| --- | --- |
| 카메라 데모 | Mac에서 모의 연결 상태가 바뀌고, Wi-Fi 안내에서 데모 사진 3장과 사진 탭을 열었다. 폰에서도 Wi-Fi 데모 사진과 사진 탭 전환을 확인했다. |
| 사진과 편집 | Mac에서 사진을 선택하고 편집 화면으로 이동했다. LUT 선택, 전체 왜곡값 0에서 30으로 변경, 원본 비교 표시를 확인했다. |
| 레시피 | Mac에서 GOLD 200과 왜곡 30으로 웹 레시피를 저장했다. 새로고침 후 이름, LUT 배지, 왜곡값이 유지됐다. |
| 테마 | Mac에서 네 가지 테마를 선택하고 페이퍼 블루를 새로고침 후 유지했다. 폰에서는 웜 앰버 전환을 확인했다. |
| 화면 배치 | Mac에서 접힌 세로, 펼친 세로, 펼친 가로 시안을 전환했다. 폰에서 카메라, 사진, 설정 화면을 열었다. |
| 사진 저장 | Mac에서 웹 JPEG 다운로드를 실행하고 파일명과 JPEG 파일 헤더를 확인했다. 실제 앱 출력과 화질은 비교하지 않았다. |

웹 레시피와 테마는 해당 브라우저에 저장된다. 웹의 LUT 색상은 실제 앱의 LUT 출력과 다를 수 있다.

## 실행하지 않은 검증

iPhone과 iPad 실기, 외부 이미지 추가, 공유 기능, 브라우저 콘솔 오류, 전체 브라우저 호환성과 JPEG 이미지 내용의 화질 비교는 확인하지 않았다. USB·Wi-Fi 사진 전송과 Android 앱의 실기 검증은 [0.8.12 검증 기록](release-0.8.12.md)을 참고한다.
