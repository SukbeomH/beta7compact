# TASK D2: 디자인 재구성 구현

근거: docs/design/{RESEARCH,IA,DESIGN-SYSTEM,PLAN}.md, docs/design/wireframes/*.svg. 이 문서를 그대로 따르되 충돌 시 IA.md 우선.

## 사용자 결정 (2026-11-16, "권장대로")
1. 테마: 항상 다크.
2. 첫 탭: USB(Sony 카메라) 연결돼 있으면 카메라 탭, 아니면 사진 탭.
3. 아이콘·폴더블: 새 라이브러리 없이 직접 구현 — Material Symbols는 필요한 아이콘만 VectorDrawable/ImageVector로 복사(Apache-2.0 고지를 NOTICE에 추가), 창 크기 판정(600/840dp)과 테이블탑 자세는 직접 구현(androidx.window가 이미 의존성에 없으면 추가 금지; 플랫폼 API·Configuration·WindowMetrics로 처리, 힌지 정보는 가능 범위만, 불가하면 근사 기준을 문서화).
4. 가져오기 완료 후: 완료 알림의 '보기' 버튼만(자동 이동 없음), 기존 자동 적용 설정 유지.
5. 레시피 탭: 보관한 레시피만(내장 LUT 목록은 편집기 스트립에서만).

## 범위
- 내비게이션: 카메라/사진/레시피/설정 4탭. 접힘 하단 탭 바, 펼침 좌측 레일. 편집기는 전체 화면(뒤로가기·예측형 뒤로가기). edge-to-edge.
- 카메라 탭: 상태 칩 하나 + 해결 버튼, 연결 시 "새 사진 N장 가져오기" 주 버튼, 선택 가져오기 화면(그리드), 진행 공용 배너. 원격 촬영·BLE 위치 자리는 비활성("준비 중") 카드.
- 사진 탭: 필터 칩, 다중 선택 모드(일괄 적용), 펼침 list-detail 2분할.
- 편집기: 사진 최대, LUT 썸네일 스트립 + 강도 슬라이더 기본, 세부(기본/톤커브/HSL/효과)는 접힌 패널, 펼침 2분할, 테이블탑 상하 분할, 슬라이더 값 손가락에 가리지 않게, 전/후 길게 누르기 유지.
- 레시피 탭: 카드 목록, 즐겨찾기, 이름 변경·복제·삭제, 공유/QR, 가져오기(코드 붙여넣기).
- 설정 탭: 홈 중복 카드 제거, 항목 정리.
- 디자인 시스템: 다크 색 토큰, 타이포, 간격, 공용 컴포넌트(상태 칩, 진행/오류 배너(항상 해결 버튼), 사진 그리드 타일, LUT 스트립, 슬라이더). 터치 48dp, 대비 기준.
- 기능 동작 불변: 가져오기·중복/해시·원본 보존·카메라 쓰기 0·로그 개인정보 0·레시피 엔진/공유 형식·DB 스키마(필요 없으면 마이그레이션 금지). BLE·RAW 기능 추가 금지.
