## 3:2 배치와 와이어프레임 대비

순수 함수 `windowClass`, `isPortraitWindow`, `paneLayout`, `photoBox`, `editorPhotoBox`, `fittedPhoto`를
`ui/UiPolicy.kt`에 분리했습니다. 내비/인셋/배너가 배치 방향을 바꾸지 않도록 방향은 전체 앱 창의
폭/높이로 결정하고, 박스 크기는 실제 가용 콘텐츠 영역으로 계산합니다.
높이 ≥ 너비인 펼침(정사각형 포함)은 상하, 가로 펼침만 좌우, 테이블탑은 방향보다 우선합니다.

| 기준 SVG / 입력 dp | 박스와 배치 |
| --- | --- |
| A / 412×915 | 412×274.6667, 앱바 아래 전폭, 아래 편집 패널 |
| B / 884×1104 | 884×589.3333, 앱바 아래 전폭, 아래 패널 좌우/하단 16dp |
| C / 1104×884 | 720×480, 왼쪽 세로 중앙, 오른쪽 패널 352dp + 간격/외곽 16dp. 높이 부족 시 박스도 같은 3:2로 축소 |
| D / 1104×884 | 위 절반 높이 442dp 안에 639×426 박스 중앙 정렬, 위 여백 8dp. 창 절반 아래 12dp 뒤 패널 시작, 뒤로/저장은 하단 조절 영역 |
| E / 884×1104 | 상세 위 884×589.3333, 아래 정보·편집/공유·적용본. 사진 탭 세로 상세에도 같은 원칙 반영 |

모든 주 사진은 검정 3:2 박스 안에서 `ContentScale.Fit`입니다. 4:3·세로 사진은 좌우 여백,
더 넓은 사진은 상하 여백을 두고 자르거나 늘리지 않습니다. 그리드/LUT 썸네일의 Crop과 구분합니다.
SVG의 275/589는 정수 반올림이고 실제 레이아웃은 정확한 2/3 높이입니다.
작은 창에서 전폭 박스 때문에 도구가 사라지지 않도록 전체 세로 스크롤로 전환합니다.

차이와 이유:

- 최신 SVG의 파란 강조색은 배치 참고로만 보고, 확정된 DESIGN-SYSTEM의 민트/중립 다크 토큰을 유지했습니다.
- A–D의 세부 탭/슬라이더가 펼쳐진 도식은 ‘세부 조정’으로 접근합니다. TASK_D2의 기본 접힘 요구를 유지했습니다.
  카테고리 필터·명시적 초기화·기존 LUT 굽기 등의 실제 기능 때문에 패널 내용은 스크롤됩니다.
- E는 그리드를 같은 화면 아래에 끼우지 않고 전체 화면 상세로 구현했습니다. 뒤로 사진 목록/선택 상태로 복귀합니다.
- E의 예시 카메라 모델·픽셀 크기 등 미수집 EXIF를 가짜로 표시하지 않습니다. 기존 DB에서 확인되는 촬영일·쌍·적용본 수를 표시합니다.
- 카메라 홈의 예시 ‘마지막 가져오기’ 썸네일/배치 통계는 만들지 않았습니다. 기존 DB에 가져오기 배치 식별자가 없어
  정확한 배치 통계를 단정하지 않고 사진 탭에서 원본을 확인하게 했습니다. DB 필드/마이그레이션은 추가하지 않았습니다.
- 레시피의 동일 JSON 적용 결과가 없으면 아이콘/안내를 표시합니다. 임의 샘플 사진이나 내장 LUT 카탈로그를 레시피 탭에 넣지 않았습니다.
- 물리 힌지 bounds는 새 Window 라이브러리 없이 얻을 수 없어 아래 근사·수동 전환을 사용합니다.

## 폴더블·접근성 한계

API 30+ `TYPE_HINGE_ANGLE` 30–150°와 회전 90/270°, 창 폭 ≥600dp로 세로가 자연 방향인
book-style 폴더블의 수평 힌지를 근사합니다. 센서가 없거나 미지원이면 자동으로 테이블탑이라고 추측하지 않습니다.
편집기에 수동 테이블탑/해제 버튼을 제공하며, 실제 힌지 위치 대신 창 높이 절반을 사용합니다.
따라서 멀티윈도우/다른 자연 방향/제조사별 센서 미노출에서는 실기 정렬을 보장하지 않습니다.
사진과 컨트롤은 추정 힌지 중심에 걸치지 않도록 여백을 둡니다.

아이콘 버튼/칩/선택 동작은 최소 48dp 타깃, 주요 아이콘은 한국어 설명을 제공합니다.
슬라이더 숫자를 위 오른쪽에 두고 보이는 초기화 버튼·기본값 눈금을 추가했습니다.
본문/보조 텍스트/버튼/오류의 대비 ≥4.5:1, 강조색과 표면의 대비 ≥3:1을 JVM에서 계산해 통과했습니다.
실제 TalkBack 읽기 순서·큰 글꼴·OEM 폴더블 렌더링은 기기 미연결로 확인하지 못했습니다.
