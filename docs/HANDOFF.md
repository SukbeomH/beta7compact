# 인계: 사진 가져오기와 편집

2026-11-19 기준. 현재 기준은 0.8.12입니다. 0.8.11은 Wi-Fi 사진 가져오기를 포함해 게시되었으며, 0.8.12는 다음 기능 정리를 반영합니다.

## 현재 결정

사용자의 실기 피드백에 따라 BLE 위치 연동과 PC Remote 원격 진단·AF·단발 촬영 실험을 종료하고 앱에서 제거했습니다. 펌웨어 파일 분석도 제거했습니다. 카메라 탭의 실험·예정 영역과 라이브뷰 안내를 없앴으며, 라이브뷰를 추가할 계획은 없습니다. 세부 실패 원인은 전달받지 않았으므로 추정하지 않습니다.

## 유지한 기능

- Sony USB MTP·읽기 전용 raw PTP 사진 목록·섬네일·가져오기와 카메라 연결 진단.
- 카메라의 스마트폰에서 선택 모드를 이용한 Wi-Fi 사진 가져오기. JPEG 원본과 카메라가 생성한 RAW의 JPEG 변환본을 구분합니다.
- 폰·외부 사진 추가, LUT·레시피·수동 왜곡, 사진 저장, 테마와 업데이트.

기존 연구·검증 문서는 당시 기록입니다. 제거된 기능을 현재 기능 또는 개발 예정으로 해석하지 마세요. [카메라 기종 조사](CAMERA_MODEL_CANDIDATES.md)의 타 제조사 모델도 검증 후보이며, 현재 앱은 Sony USB 장치를 대상으로 합니다.

## 남은 확인

사용자가 α7C 실기에서 Wi-Fi 목록·섬네일·JPEG 전송·RAW의 JPEG 변환 결과를 추후 확인합니다. 설정은 **카메라 → Wi-Fi로 사진 가져오기**에서 확인합니다. USB MTP 가져오기와 사진 편집도 회귀 확인합니다. 카메라 사진과 앱의 기존 데이터는 보존합니다.

빌드와 APK 서명·폰 설치 결과는 [0.8.12 검증 기록](verification/2026-11-19/release-0.8.12.md)을 참고하세요. 기존 설치본과 같은 키인지 [서명키 관리](SIGNING.md)에서 확인하고, 서명이 다르면 앱을 지우지 말고 중단합니다. `tools/check_m5a_contract.py`와 `tools/check_d2_contract.py`는 0.4.0 기준의 역사적 검사입니다.

## 공개 웹 미리보기

[Screen Studio](https://beta7c-screen-studio.robust-zebra-1280.chatgpt.site/)는 전체 공개 상태입니다. GitHub README에서 바로 열 수 있습니다. 실제 Android 스크린샷이 아니며 카메라 전송은 모의 동작입니다. 웹 LUT와 JPEG 결과는 앱의 결과와 다를 수 있습니다.

2026-11-19에 로그인 정보 없는 HTTP 접속, Mac Aside 브라우저, Samsung SM-F971N의 삼성 인터넷에서 주요 화면을 확인했습니다. Mac에서 레시피 저장과 새로고침 후 유지, 네 가지 테마, 웹 JPEG 다운로드를 확인했습니다. 폰에서는 Wi-Fi 데모 목록과 사진·설정 화면 전환을 확인했습니다. 범위와 미실행 항목은 [공개 미리보기 검증 기록](verification/2026-11-19/screen-studio-public.md)을 참고하세요. 로컬 실행 방법은 [시안 README](../sites/beta7c-screen-studio/README.md)에 있습니다.
