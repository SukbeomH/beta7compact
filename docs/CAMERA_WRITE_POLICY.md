# 카메라 쓰기 원칙

2026-11-18 개정. 앱이 카메라에 무엇을 써도 되는지의 단일 기준입니다. 다른 문서의 "설정 쓰기 없음" 서술과 다르면 이 문서를 따릅니다.

이전 원칙은 "카메라 설정을 쓰지 않는다"였습니다. 원격 촬영과 위치 연동은 카메라 상태를 바꾸지 않고는 동작하지 않으므로, 금지 대신 **허용 목록과 조건**으로 바꿉니다. 목록에 없는 쓰기는 여전히 하지 않습니다.

## 1. 하지 않는 것

어떤 기능에서도 보내지 않습니다.

- 사진 삭제·포맷, 펌웨어 쓰기·업데이트 명령, USB 구성 SET 명령
- 임의 opcode·임의 속성 코드·임의 값을 받는 쓰기 API. 쓰기는 코드에 고정된 enum으로만 표현합니다.
- 추측으로 만든 명령. 공개 근거가 없는 값은 쓰지 않습니다.
- 읽기 전용 진단(카메라 연결 진단, 펌웨어 파일 분석)에서의 모든 쓰기
- 사용자가 실행하지 않은 자동 쓰기(앱 시작, 백그라운드, 재시도)

## 2. 허용 목록

아래 항목만 씁니다. 각 항목은 지정된 화면에서 사용자가 그 실행을 확인했을 때만 동작합니다.

| 대상 | 쓰는 값 | 어디서 | 되돌림 | 근거 | 실기 |
| --- | --- | --- | --- | --- | --- |
| Sony 세션 연결 `0x9201` 1·2·3단계 | 고정 파라미터 | PC Remote 실험 진단, AF·단발 촬영 실험 | 세션 종료. 카메라 모드 원복은 보장 못 함 | libgphoto2 `31a2f408` | 미확인 |
| 반셔터 `0xD2C1`, 셔터 `0xD2C2` (`0x9207`) | 누름 2, 해제 1 | AF·단발 촬영 실험 | 누른 순서의 반대로 해제 | libgphoto2 | 미확인 |
| **제어 우선순위 `0xD25A` (`0x9205`)** | 1(Application). 되돌릴 때 0 | AF·단발 촬영 실험, 확인란을 켠 실행 | 쓰기 전 값이 0이었으면 끝날 때 0을 쓰고 재조회 | libgphoto2 `library.c:777`(3단계 연결 직후 INT8 1, 버전 조건 없음, 실패는 기록만), AlphaWire(1바이트, 0=Camera·1=Remote로 정의) | 미확인 |
| BLE 위치 `DD11`, 상태 구독 `DD01` CCCD | 위치 패킷, 구독 값 | BLE 위치 연동 | 연결 종료 | ILCE7M3ExternalGps 프로토콜 문서 | 미확인 |
| BLE 잠금 해제 `DD30`, `DD31` | 01. 되돌릴 때 00 | BLE 위치 연동, 확인란을 켠 실행 | 끌 때 00 | 프로토콜 문서, Alpha GPS | 미확인 |

제어 우선순위는 이번 개정으로 추가한 항목입니다. 촬영 실험은 이 값이 1이어야 진행하는데, 공개 구현은 연결 직후 직접 쓰고 앱은 쓰지 않아 실기에서 거부될 가능성이 컸습니다. AlphaWire는 같은 속성을 "Dial Mode"라고 부릅니다. 1인 동안에는 카메라의 모드 다이얼 대신 원격 쪽 설정이 우선한다는 뜻으로 읽히므로, 끝날 때 되돌리는 것이 중요합니다. 되돌림이 확인되지 않으면 카메라 전원을 껐다 켜거나 PC Remote를 꺼서 확인합니다.

## 3. 항목을 추가하는 조건

새 쓰기는 아래를 모두 채운 뒤 이 표에 올리고 구현합니다.

1. **근거 두 개.** 서로 독립적인 공개 구현 둘, 또는 Sony 공식 문서 하나에서 값·타입·순서가 일치합니다. 코드는 가져오지 않고 사실만 씁니다.
2. **고정된 표현.** 대상 코드와 값을 enum에 고정합니다. 호출부가 값을 고를 수 없습니다.
3. **쓰기 전 확인.** 속성이 존재하고, 타입이 예상과 같고, 쓰기 가능·활성으로 조회될 때만 씁니다. 하나라도 다르면 쓰지 않고 그 사실을 로그에 남깁니다.
4. **쓴 뒤 재조회.** 값이 바뀐 것을 다시 읽어 확인합니다. 응답 코드만으로 성공을 판단하지 않습니다.
5. **되돌림.** 쓰기 전 값을 기억해 끝날 때 되돌립니다. 되돌림이 확인되지 않으면 "미확인"으로 표시하고 사용자가 카메라에서 확인하도록 안내합니다.
6. **실행마다 확인.** 그 실행에 한한 확인란 또는 확인 대화상자를 거칩니다. 설정에 저장해 두고 자동으로 켜지 않습니다.
7. **증거.** 쓰기의 시작·응답·재조회 결과·되돌림 결과가 공유 로그에 남습니다.
8. **실기 전 표시.** 실기에서 확인하기 전에는 화면과 문서에 "실기 미검증"으로 적습니다.

## 4. 아직 허용하지 않는 후보

근거는 있으나 위 조건을 채우지 않아 쓰지 않습니다.

| 후보 | 남은 것 |
| --- | --- |
| ISO·조리개·셔터속도·노출보정 | 프로토콜 버전(0x00C8/0x012C)에 따라 직접 설정과 단계 이동으로 갈립니다. 실기 진단으로 버전과 타입을 먼저 확인합니다. |
| 저장 위치 `0xD222` | 카드에 남지 않는 설정으로 바꾸면 사진을 잃을 수 있습니다. 저장 확인 경로(`0xFFFFC001`)를 설계한 뒤 검토합니다. |
| 라이브뷰 화질 `0xD26A` | 라이브뷰 수신 자체가 먼저입니다. 수신은 읽기라 이 표의 대상이 아닙니다. |
| BLE 페어링 명령 `EE01`, 리모컨 `FF01` | OS 본딩만으로 되는지 실기에서 먼저 확인합니다. |

## 5. 로그에 남기는 값

쓰기를 판단하려면 카메라 상태를 읽어야 하므로, 공유 로그는 다음 값을 포함합니다. 기기를 식별하는 값(시리얼, 기기 문자열, 주소, 경로), 사진, 좌표, 원시 응답은 넣지 않습니다.

- PC Remote 실험 진단: 조건 속성 13개의 타입·접근·현재값([목록](PC_REMOTE_DIAGNOSTICS.md))
- AF·단발 촬영 실험: 제어 우선순위 처리 결과(쓰기 여부, 재조회, 되돌림)
- BLE 위치 연동: 광고의 상태 바이트, 특성 목록, `DD21`·`DD01` 원문, 잠금 해제 결과
