# 사진 전체 수동 왜곡 조절

2026-11-18. 사용자 요청으로 렌즈 프로파일 자동 보정은 보류하고 기존 편집기의 전체 사진 효과로 추가했다. 0.8.7(20)에 포함한다. [배포 검증](verification/2026-11-18/release-0.8.7.md). 실제 사진 품질 평가는 후속 진행이다.

## 사용 방법

1. 사진을 선택하고 편집기의 **세부 조정 → 왜곡** 탭을 연다.
2. 기본값은 **0 · 꺼짐**이다. 음수는 배럴, 양수는 핀쿠션 방향의 전체 사진 변형이다. 표시 범위는-100~100이며 물리적인 왜곡률/퍼센트가 아니다.
3. 원본 비교로 효과를 확인한다. 초기화로 정확히0으로 돌아가며 실행 취소·다시 실행도 사용할 수 있다.
4. **사진 저장**은 변형된 결과를 기존 JPEG 저장 경로로 보낸다. 원본 파일은 덮어쓰지 않는다.
5. **레시피 저장**에는 조절값이 포함된다. 공유/다른 사진/일괄 적용에도 같은 수동 효과가 적용되므로 사진별로 확인한다. 렌즈별 자동 선택은 하지 않는다.

빈 테두리가 생기지 않도록 원본의 내부 영역을 사용하며 일부 가장자리와 화각이 손실된다. 출력 픽셀 크기가 같아도 실제 담긴 범위는 달라질 수 있다. 별도 확대/크롭 슬라이더나 카메라 보정 역복원은 제공하지 않는다. 이미 보정된 JPEG에도 추가 효과를 주는 것이며 정확한 렌즈 교정·얼굴 복원이라고 해석하지 않는다.

색 보정 초기화는 입력 변환과 왜곡을 유지한다. 왜곡만 초기화하려면 해당 조절의 초기화를 사용한다. `.cube`는 색 변환만 담으므로 수동 왜곡·그레인·비네트는 제외되며 화면 안내와 파일 주석에 표시한다.

최종 배치와 문구는 [디자인 규칙 검토](MANUAL_DISTORTION_DESIGN_REVIEW.md)에 기록했다.

## 구현과 호환성

- `recipe/ManualDistortion.kt`: 독립 작성한 전체 사진 역매핑, 원본 좌표 기반 스케일/영역 계산, bilinear 샘플링, 행 단위 취소 확인. 제조사 LCP·Lensfun 데이터·Sony 전용 명령·얼굴 모델을 사용하지 않는다.
- 화면 중심과 반대각선 길이를 기준으로 방사형 함수를 적용한다. 내부 강도는 `k=-0.18*amount`로 제한하고 배럴 방향에서는 경계가 원본 내부에 머물도록 스케일을 계산한다. 사용자값은 실제 렌즈 계수나 촬영 조건과 대응하지 않는다.
- `recipe/DistortionRenderer.kt`: 미리보기의 원본 크기 좌표와 내보내기의 원본 좌표를 같은 모델에 연결한다. 내보내기는 출력 타일의 역매핑에 필요한 입력 영역과 보간 이웃을 읽는다. 타일마다 독립 중심을 두거나 영역 밖 픽셀을 반복해 빈 테두리를 채우지 않는다.
- `PhotoRenderer.kt`와 `RecipeScreen.kt`: 기하 변형 → 기존 GPU 색 처리 → EXIF 방향 정립 순서를 사용한다. 기존 원해상도 출력 비트맵/메모리 제한을 유지하고 임시 영역/출력 타일만 추가한다. 값0은 기존 미리보기/내보내기 경로를 사용해 불필요한 리샘플링을 건너뛴다.
- `Recipe.kt`: 기본값/기존 v1·v2 레시피는0. 새로운 왜곡 설정을 사용하면 레시피 v3으로 저장한다. v3은 필수 `distortion`과 `colorVersion` 값을 검증하고 이전 버전에 왜곡 값을 넣은 입력은 거부한다. v3 레시피는 구버전 앱에서 읽을 수 없으며, 효과가 조용히 무시되는 공유를 피한다. 사진 DB 스키마는 변경하지 않는다.
- `CpuEngine.kt`와 `GpuEngine.kt`: 직렬화 버전과 색 처리 순서를 분리해 v3에서도 기존 v1/v2 색 처리 순서를 유지한다. `ColorEditor.kt`는 색 조절 시 v3을v2로 낮추지 않는다. `UiPolicy.kt`의 수정 여부 판정도 v3 값에서 예외가 나지 않게 정규화한다. 레시피 JSON·공유 코드·저장 대기열·히스토리의 기존 경로를 재사용한다.

원본에0으로 적용하면 항등이지만 사진 저장은 기존 경로대로 JPEG 재압축한다. 미리보기는 다운샘플링본에 보간하고 원해상도는 원본 픽셀에 보간하므로 축소 미리보기와 저장 파일의 세부 선명도가 같다고 보장하지 않는다. Android 실제 디코더/GPU에서의 효과·EXIF8방향·속도/메모리·인물 자연스러움은 후속 실기 범위다.

## 검증

[빌드·테스트 결과와 미실행 항목](verification/2026-11-18/manual-distortion.md)에 실행 로그와 결과를 기록한다. 합성 픽셀 테스트는 변환과 경계 처리의 검증이며 실제 사진의 미감/선호도를 입증하지 않는다.

실제 사진 평가는 사용자가 후속 진행한다. 낮은 강도부터 배경 직선, 중앙/주변부 인물, 모서리 디테일, 화각 손실, 미리보기/저장 위치 대응을 확인하고 원본이 더 자연스러우면0으로 유지한다.
